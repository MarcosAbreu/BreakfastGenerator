# Breakfast Generator
DISCLAIMER: This tool is developed for educational proporse only.

## About the project

This application was created for coding training proporse only.

This tool works as a random pick app of available breakfast meals, where you can select how long will take to prepare the meals. Also, along sided with the recomended serving, its possible to check the recipe of each meal, if available. 

This project was developed following the nutricionist recomendation to myself and should not be followed without professional recomendation.

In this tool you can add to Available Meals List any of database meals or select temporarily added meals.

## How it works
It's very simple to use the app. Basically, it works with 3 sections, as we can see in the image below: Configuration (Section A), Available Meals List (Section B) and Generated Breakfast Results (Section C).

![breakfast-generator-screenshot-2](https://user-images.githubusercontent.com/7178382/212565714-6392148d-c3f9-4045-bec7-4cbaa71d8ddb.png)

The required actions to generate the breakfast is selecting the desired preparation time checkbox and press "Generate Breakfast" button, as showed in screenshot below. Then, the breakfast will be generated based in the List of Available Meals.

![breakfast-generator-screenshot-3](https://user-images.githubusercontent.com/7178382/212565710-4efe91a4-06f3-4ad6-bc60-61c5ddca1fa2.png)

Also, before generating the Breakfast, it is possible to add in the list by searching the meal in the database, as showed below.

![breakfast-generator-screenshot-4](https://user-images.githubusercontent.com/7178382/212565711-6a64deb2-6ccc-445d-b5a4-8b74a317e3f9.png)

### Extra Featuring

Sometimes, there is some meals that are not registered, in this case, you can add new meals temporarily with or without recipe ingredients and steps.

## How to run the project

First, you have to clone or download the project.
```bash
git clone https://github.com/MarcosAbreu/BreakfastGenerator.git
```
Then go to project folder and open the file `BreakfastGenerator\app\html\index.html` using Visual Studio Code extension Live Server
